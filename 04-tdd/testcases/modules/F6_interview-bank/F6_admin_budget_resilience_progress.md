# F6 budget integration, resilience, and topic progress — test cases

Status: **Draft; Chưa thực hiện**.

## Shared fixture and environment

- **Environment:** F6 API with F5 budget/token ports, controllable AI adapter, Redis, F1–F4 integrations, PostgreSQL and event/outbox inspection; isolated integration stack. Actors S1 STUDENT, G1 INSTRUCTOR, Q ADMIN.
- **Data:** active question Q-X with rubric weights 30/40/30 in topic T-DB; answer IDs generated by server. S1 has two other active questions and an attempted question in T-BEH. Seed exact practice answers/history and budget states per case.
- **Evidence:** ordered call trace with role/category, HTTP response, `user_answers`, `practice_history`, token usage, Redis key/TTL, F4 submission records, and emitted-event/outbox rows. Mask answer text in logs/evidence.
- **Cleanup:** restore budgets, Redis counters and seeded progress; delete disposable attempts/records only after evidence capture. All cases remain Chưa thực hiện.
